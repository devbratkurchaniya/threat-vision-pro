# 🛡️ Threat Vision Pro - Enterprise SOC Threat Intelligence Portal

Threat Vision Pro ek advanced Python aur Streamlit-based Security Operations Center (SOC) dashboard hai jo real-time log analysis, multi-layer threat scoring, URL forensics, aur MITRE ATT&CK mapping provide karta hai.

## 🚀 Key Features
- **Multi-Layer Threat Scoring Engine**: Pattern matching, anomaly detection, aur IP reputation.
- **URL Forensics & OSINT**: Detection of look-alike domains, homograph attacks, and obfuscated URLs.
- **Interactive Dashboards**: Dynamic Plotly charts for SOC metrics, threat timeline, and live feeds.
- **Mitigation Recommendations**: Automated firewall rules (iptables/fail2ban) and mitigation steps.
- **Audit Logging & Export**: Built-in security audit logs and JSON/CSV reporting.
